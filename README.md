# Ecommerce_analysis

Phân tích dữ liệu thương mại điện tử **E-Commerce Customer Behavior & Sales (2020–2026)** (25.000 đơn hàng, 8.000 khách hàng, 20 quốc gia, 14 nhóm hàng) cho môn Trực quan hóa dữ liệu. Dự án đi từ làm sạch dữ liệu, phân tích theo 10 câu hỏi, đến dashboard tương tác bằng **Plotly Dash** dùng chung một nguồn dữ liệu sạch.
